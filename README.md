# 🧹 AI-Powered Data Cleaning & Analysis Tool

An interactive Python and Streamlit application that helps users clean, analyze, and visualize CSV and Excel datasets without writing complex code.

## 🚀 Features

- 📂 Upload CSV and Excel files
- 📊 Dataset overview dashboard
- ⚠️ Missing value detection and cleaning
- 🔁 Duplicate detection and removal
- 🗑️ Unwanted column removal
- 📋 Before vs After comparison
- 📈 Interactive Plotly visualizations
- 📊 Statistical analysis
- 🚨 IQR-based outlier detection
- 🤖 Automated data summary
- 💡 Cleaning recommendations
- 💯 Data quality score
- 📥 Download cleaned CSV
- 📥 Download cleaned Excel

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Streamlit
- OpenPyXL
- Statsmodels

## 📊 Visualizations

The application provides:

- Histogram
- Box Plot
- Correlation Heatmap
- Scatter Plot
- Category Bar Chart
- Line Chart

## 🧠 How It Works

1. Upload a CSV or Excel dataset.
2. The application analyzes the dataset.
3. Missing values and duplicate records are detected.
4. Users can apply cleaning operations.
5. Statistical information is generated.
6. Interactive charts are created.
7. Outliers are detected using the IQR method.
8. A data quality report is generated.
9. The cleaned dataset can be downloaded as CSV or Excel.
